Contêiner padrão de conteúdo. Nunca use borda colorida só à esquerda — não faz parte da linguagem visual.

```jsx
<Card title="Tempo por etapa" subtitle="Últimas 24h" actions={<IconButton icon="download" label="Exportar" />}>
  …
</Card>
```

`padding="none"` quando o corpo é uma tabela de ponta a ponta.
