One attribute bar, RPG-style. Stack six for the hunter's full attribute panel.

```jsx
<StatBar attr="strength" value={72} />
<StatBar attr="agility" value={54} />
<StatBar attr="endurance" value={88} />
<StatBar attr="vitality" value={61} />
<StatBar attr="focus" value={40} />
<StatBar attr="wisdom" value={55} />
```

Colors are fixed per attribute so users learn them — don't recolor. Default labels are PT-BR (Força, Agilidade, Resistência, Vitalidade, Foco, Sabedoria).
