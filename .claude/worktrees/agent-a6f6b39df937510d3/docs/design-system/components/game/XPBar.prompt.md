Gold XP / level progress bar. The fill animates its width (great for level-up moments) and carries a top sheen.

```jsx
<XPBar level={37} value={640} max={900} />
<XPBar value={20} max={100} showValues={false} height={8} />
```

Pass `level` to show the "Nível N" label. Always the gold gradient — XP is gold across the brand; rank uses color, XP stays gold.
