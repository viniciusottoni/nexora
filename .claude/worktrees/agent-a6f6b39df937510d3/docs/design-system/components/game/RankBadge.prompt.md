The signature Awaken motif — a faceted hexagonal shield that glows in the rank's color. Use it on the profile card, level-up reveals and leaderboards.

```jsx
<RankBadge rank="S" size={88} />
<RankBadge rank="E" size={48} glow={false} />
```

Ranks ladder E → D → C → B → A → S → SS → SSS, each with its own color. SS/SSS use multi-stop gradients. Keep `glow` on for hero placements; turn it off in dense lists.
