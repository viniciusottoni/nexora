Tiny uppercase pill for status and metadata. Default `soft` tint reads well on dark surfaces; `solid` for high-emphasis flags.

```jsx
<Badge tone="gold" variant="solid">PREMIUM</Badge>
<Badge tone="cyan">NOVO</Badge>
<Badge tone="green" variant="outline">+250 XP</Badge>
```

Tones: `blue purple gold green red cyan neutral`. Variants: `soft | solid | outline`. Keep labels to 1–2 words.
