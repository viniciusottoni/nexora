The primary tap target across Awaken — uppercase display type, energy-gradient fill, optional glow for hero moments.

```jsx
<Button variant="primary" glow onClick={start}>Iniciar Quest</Button>
<Button variant="gold" size="lg" fullWidth>Desbloquear S-Rank</Button>
<Button variant="ghost" size="sm">Pular</Button>
```

Variants: `primary` (blue→purple energy), `gold` (premium/XP), `secondary` (outlined surface), `ghost` (low emphasis), `danger`. Sizes `sm | md | lg`. Set `glow` only on the single most important CTA on a screen. All labels are uppercased automatically.
