# ADRs — AWAKEN

Este diretório contém os Architecture Decision Records do projeto AWAKEN.

## Arquivos criados

- ADR-001 — Flutter como frontend mobile oficial
- ADR-002 — ASP.NET Core como backend oficial
- ADR-003 — Modular Monolith no MVP
- ADR-004 — PostgreSQL como banco principal
- ADR-005 — Redis para cache e controle operacional
- ADR-006 — RevenueCat para assinaturas
- ADR-007 — Firebase para push, analytics e crash
- ADR-008 — Cloudflare R2 para storage (substituído pela ADR-024)
- ADR-009 — Backend como autoridade de XP, rank e streak
- ADR-010 — Idempotência para conclusão de quest
- ADR-011 — Estratégia offline parcial
- ADR-012 — Geração de treino híbrida
- ADR-013 — Treino de reserva
- ADR-014 — Dados pessoais e LGPD
- ADR-015 — Logs sem dados sensíveis
- ADR-016 — Android mínimo
- ADR-017 — Expansão para iOS
- ADR-018 — CI/CD
- ADR-019 — Observabilidade
- ADR-020 — Backup e recuperação
- ADR-021 — Multi-language: português, inglês e espanhol
- ADR-022 — Inventário e loja: escopo mínimo funcional
- ADR-023 — Fundação de economia: carteira de Gold, rastreamento unificado de compras e auditoria
- ADR-024 — Storage de objetos: bucket S3-compatível (Railway)

## Regra de uso

Antes de implementar fundação, mobile, backend, assinatura, progressão, notificações, internacionalização, inventário/loja, economia/carteira ou infraestrutura, consultar o ADR correspondente.
