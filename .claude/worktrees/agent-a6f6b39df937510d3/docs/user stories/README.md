# AWAKEN — User Stories por Épico

Esta pasta organiza o backlog do MVP Android Fitness Gamificado por épicos.

Cada subpasta contém um `README.md` com o detalhamento do épico, incluindo objetivo, contexto, escopo, fora de escopo, User Stories relacionadas, impactos técnicos, dependências, critérios de aceite e decisão registrada.

## Modelo comercial considerado

O backlog considera a decisão vigente do produto:

> O usuário poderá testar gratuitamente por 7 dias. Após esse período, deverá assinar o plano mensal ou anual para continuar usando o AWAKEN.

Não existe plano gratuito permanente no MVP. O conceito de `Free Hunter` foi substituído por:

- Usuário em Trial;
- Premium Mensal;
- Premium Anual;
- Trial expirado;
- Assinatura expirada.

## Ordem recomendada de implementação

1. Fundação mobile e experiência base.
2. Conta, sessão e segurança inicial.
3. Trial, assinatura e bloqueio de acesso.
4. Onboarding.
5. Catálogo e geração de treino.
6. Edição e execução da quest.
7. Gamificação.
8. Perfil, card e histórico.
9. Analytics, crash, segurança e privacidade.
10. Site admin e monitoramento operacional.
11. Economia, loja e inventário.
12. EPIC-020 de hardening de segurança, performance e escalabilidade do MVP.
13. EPIC-021 de refinamento de loja, programas e perfil.
14. Release Android e qualidade.
15. P1 do MVP, se houver tempo antes do lançamento.
