# US-130 / US-133 / US-134 — Attribute Internal XP, Level-Up Reward, XP Bars

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add internal XP buffer per attribute (0–9 → +1 Level at 10), show attribute level-ups on quest reward screen, show XP progress bar per attribute in hunter profile.

**Architecture:**
- US-130 (backend-only): `HunterProgression.AddAttributeXp()` accumulates XP per attr; when buffer ≥10, Level++ and buffer -= 10 (excess preserved). Level capped at 10.
- US-133 (backend+frontend): `CompleteExerciseResponse` and `QuestRewardSummaryResponse` gain `attributeLevelUps: List<string>`. Reward page highlights leveled-up attrs.
- US-134 (backend+frontend): `HunterProfileResponse` gains `attributeXp: AttributeXpDto`. Profile page shows sub-bar (0/10) per attribute.

**Tech Stack:** C# (.NET 10), FluentAssertions, EF Core migrations, Flutter/Dart, Riverpod, ARB i18n.
